# 图书管理系统

一个简洁的图书管理工具，支持图书的增删改查、借阅归还等基本操作。

## 功能

- 图书管理：添加、删除、修改、查询图书信息（书名、作者、ISBN、分类等）
- 借阅管理：图书借出与归还，记录借阅人及借阅日期
- 读者管理：读者信息登记与维护
- 查询统计：按书名、作者、分类等条件检索，借阅记录统计

## 技术栈

- 后端：Java / Spring Boot
- 数据库：MySQL
- 前端：Vue.js + Element UI

## 快速开始

1. 克隆项目
2. 导入数据库脚本（见 sql/ 目录）
3. 修改 application.yml 中的数据库连接信息
4. 启动后端服务：mvn spring-boot:run
5. 启动前端：npm run serve
6. 访问 http://localhost:8080
